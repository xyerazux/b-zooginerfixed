# Ikon B-zooginer
Ikon SVG orisinal (gaya flat) untuk tema kebun binatang. Untuk menggantinya dengan ikon dari Icons8 / Phosphor / Magnific,
simpan berkas baru dengan nama yang sama. Rasio persegi (viewBox 64x64 disarankan). Cek lisensi sumber sebelum rilis publik.
Daftar: lion, tiger, elephant, giraffe, zebra, monkey, monkey-cover, monkey-hear, panda, parrot, owl, turtle, hedgehog,
butterfly, bee, leaf, plant, paw, paw-white, banana, star, heart, cloud, crown, balloon, bamboo, smile, check-white.
